# Airgap Sentinel

A secure log ingestion and monitoring system for airgapped environments.

## Backend Stack

- **Framework:** FastAPI
- **Language:** Python 3.9+
- **Database:** PostgreSQL
- **Server:** Uvicorn

## Getting Started

### Prerequisites

- Python 3.9+
- PostgreSQL 12+
- pip or poetry

### Setup

1. Clone the repository
```bash
   git clone https://github.com/azimfathima999/airgap-sentinel.git
   cd airgap-sentinel
```

2. Create a virtual environment
```bash
   python -m venv venv
   source venv/bin/activate
```

3. Install dependencies
```bash
   pip install -r requirements.txt
```
